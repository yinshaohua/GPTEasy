# GPTEasy UI Design Contract

## Design Direction

GPTEasy 采用轻量、克制、具有原生系统工具感的桌面伴侣程序风格。界面首先服务于非技术用户的供应商配置和切换，不模仿聊天应用，也不采用开发者管理面板的高信息密度。

### Principles

- 托盘优先，设置窗口按需打开。
- 默认只展示完成当前任务所需的信息，技术细节按需展开。
- Windows 与 macOS 使用一致的产品语言，同时尊重各平台的窗口、间距和交互习惯。
- 浅色与深色主题跟随操作系统。
- 使用清晰的状态图标、状态文本和操作结果，不只依赖颜色传达状态。
- 动效克制，只用于状态变化和操作反馈。

### Avoid

- 模仿 ChatGPT 或其他聊天应用的界面。
- 霓虹渐变、大面积玻璃效果和持续发光。
- 机器人、聊天气泡和无实际信息价值的 AI 插图。
- 默认展示完整请求、响应、配置文件或诊断日志。
- 只适合开发者理解的密集表格和术语堆叠。

## Color

- 使用低饱和度靛蓝作为固定品牌强调色。
- 浅色主题使用偏深的靛蓝，深色主题使用亮度更高的靛蓝。
- 品牌色用于主操作、选中状态、链接和焦点，不表示验证成功。
- 成功使用绿色，警告使用琥珀色，错误使用红色。
- DayWay 的内置推荐标签使用柔和的品牌色背景，不使用刺眼金色。
- 不使用大面积蓝紫渐变。
- 所有状态在颜色之外同时使用图标或文本表达。

## Window Structure

设置窗口使用左侧边栏，不设置独立仪表盘首页。

1. **供应商**：默认页，顶部展示原生 Codex 环境当前状态，下方管理供应商。
2. **WSL2**：只在 Windows 显示，管理各发行版默认用户的当前供应商及批量切换。
3. **Linux 脚本**：选择 Shell 和脚本语言，展示凭据警告并导出脚本。
4. **设置**：管理原厂登录模式、登录启动、界面语言、更新检查、诊断日志和版本信息。

macOS 不显示空的 WSL2 导航项。

## Provider List

- 使用紧凑卡片列表，不使用大型营销卡片或数据表格。
- DayWay 始终位于设置列表第一项。
- 每项显示名称、推荐标签、服务主机名、默认模型、验证状态、最近验证时间和当前使用状态。
- 未配置的 DayWay 显示“开始配置”主操作。
- 已验证且不是当前供应商时显示“切换”操作。
- 当前供应商使用选中边框和“当前使用”标签，不突出重复切换操作。
- API Key 不在列表中展示。
- 点击供应商后进入统一的完整供应商页面，不使用右侧详情面板。
- 编辑以外的低频或危险操作放入更多菜单。
- 供应商较多时提供搜索，不使用分页。

## Provider Page

- 查看、新增和编辑供应商使用同一种完整单页结构，不使用详情面板、模态弹窗或分步骤向导。
- 新增供应商时显示空白页面；打开已有供应商时在相同位置展示其完整配置和状态。
- 名称、服务地址、API Key、模型获取、默认模型、验证进度和结果在同一页面展示。
- 字段按照依赖关系从上到下排列，但不隐藏后续区域。
- 服务地址和 API Key 不完整时，获取模型操作保持禁用并说明原因。
- 尚未选择默认模型时，完整验证操作保持禁用并说明原因。
- 验证过程在页面内展示每个检查项的等待、进行中、成功或失败状态。
- 只有完整验证成功后才允许保存关键配置。
- 只修改不影响服务能力的字段时，不要求重新验证。
- 打开已有供应商后字段直接可编辑，不设置单独的只读查看模式。
- 没有修改时保存操作禁用。
- 修改服务地址、API Key 或默认模型后显示需要重新验证，验证成功前不能保存。
- 离开存在未保存修改的页面时提示用户是否放弃修改。
- 删除操作放在页面底部的危险区域。
- 新增供应商时 API Key 默认明文显示。
- 打开已保存供应商时 API Key 默认隐藏，可通过眼睛按钮完整显示并通过复制按钮复制。
- 离开页面后再次打开时恢复隐藏状态，不要求系统密码才能查看。
- 截图辅助、诊断导出和错误信息不显示 API Key。

## Provider Validation

- 使用三项纵向检查列表，不使用只有百分比的进度条。
- 检查项依次为默认模型确认、Responses API 流式响应、工具调用闭环。
- 等待使用灰色圆点，进行中使用靛蓝活动图标，成功使用绿色勾，失败使用红色感叹号。
- 失败后停止后续步骤，不能跳过失败项。
- 默认展示面向非技术用户的简短错误说明。
- HTTP 状态码和原始技术错误放入可展开的“技术详情”。
- 提供复制错误操作，但不包含完整请求、响应正文或 API Key。
- 全部成功后展示验证时间并启用保存。

## Restart Prompt

- 检测到原生 Codex 进程运行时，切换前使用原生确认对话框。
- 对话框展示当前供应商、目标供应商、运行中的 Codex 类型以及任务中断警告。
- “切换并立即重启”为视觉主按钮。
- “切换，稍后重启”为普通次按钮，“取消”为弱化操作。
- 不使用倒计时或自动选择，键盘默认不直接触发立即重启。
- 选择稍后重启后，托盘图标显示状态圆点，托盘顶部展示等待重启状态和目标供应商。
- 按钮顺序遵循 Windows 与 macOS 各自的平台习惯。

## Tray Menu

- 托盘只切换原生 Codex 环境的已验证供应商，不提供 WSL2 快捷操作或状态摘要。
- 顶部展示当前供应商、原厂登录模式、外部配置或待重启状态。
- 已验证 DayWay 排在供应商区第一项，当前供应商使用勾选标记。
- 原厂登录模式不与供应商并列，只能在设置中启用。
- 当前处于原厂登录模式时，点击供应商会提示将切换回代理 API 模式。
- 供应商区下方只提供“设置…”和“退出 GPTEasy”。
- “设置…”打开设置窗口并默认进入供应商页面；WSL2、Linux 脚本和通用设置通过左侧边栏进入。

## Iconography

- 应用图标采用原创的“G + 双向切换路径”概念。
- 不使用 OpenAI、ChatGPT、机器人或聊天气泡图形。
- 应用图标使用靛蓝底色和浅色主体。
- Windows 托盘使用在 16×16 像素仍清晰的单色轮廓。
- macOS 菜单栏使用可由系统适配明暗状态的模板图标。
- 待重启状态使用小圆点附加标记，不更换完整图标。
- 图标中不放入完整的 GPTEasy 文字。

## Typography

- 使用各平台系统字体，不捆绑网络字体或品牌字体。
- Windows 使用 Segoe UI 系列及系统中文字体回退。
- macOS 使用 San Francisco 系列及系统中文字体回退。
- 服务地址、模型 ID、API Key、配置路径和技术错误使用系统等宽字体。
- 正文保持舒适字号，不通过过度缩小字体提升信息密度。
- 标题层级主要通过字号和字重区分，不大量使用全大写或彩色标题。

## Layout Density

- 默认窗口约为 960×680，并允许用户调整大小。
- 设置合理最小尺寸，避免字段和操作挤压。
- 左侧边栏保持固定窄宽度，表单内容设置最大宽度。
- 使用统一的 8 像素间距体系和中等高度控件。
- 卡片使用克制圆角、细边框和轻微层次，不使用厚重阴影。
- 大区域之间明显分隔，区域内部保持紧凑。
- 长服务地址和模型 ID 单行省略，悬停或聚焦后显示完整值。
- 小窗口使用纵向滚动，不切换为手机式抽屉导航。

## Theme

- 默认跟随操作系统浅色或深色主题。
- 设置中允许选择跟随系统、浅色或深色，修改后立即生效。
- 不提供自定义主题或自定义强调色。
- 托盘图标依据系统任务栏或菜单栏主题适配，不依据应用窗口主题。
- 深色主题分别定义背景、边框、文本和状态色，不使用简单反色。
- 高对比度模式优先遵循系统可访问性设置。

## First Run

- 首次启动直接进入正常供应商页面，不使用多步骤欢迎向导。
- 页面顶部使用简短欢迎横幅展示原生 Codex 环境检测结果。
- 未检测到桌面应用时提供官方安装建议，但不阻止其他功能。
- 没有已验证供应商时直接展示 DayWay 和新增供应商入口。
- 欢迎横幅包含配置供应商、首次自动切换和登录启动选择的简短清单。
- 登录启动选择在当前页面完成，不打开额外向导窗口。
- 首个供应商配置完成后自动收起欢迎横幅。
- 帮助区域允许用户重新查看入门说明。

## Feedback

- 页面内状态用于验证进度、WSL2 批量结果、外部配置、待重新验证、待重启和字段错误。
- 应用内 Toast 用于保存成功、脚本复制成功、设置修改成功和轻量错误。
- 系统通知只用于窗口不可见时的托盘切换结果、后台批量操作完成、版本更新和稍后重启提醒。
- 模态对话框只用于重启选择、放弃修改、删除供应商、明文脚本导出警告和需要用户决定的恢复操作。
- 同一结果不同时使用 Toast 和系统通知重复报告。
- 不使用连续成功对话框。
- 通知和错误正文不包含 API Key 或完整服务地址。

## Accessibility

- 所有核心功能可以通过键盘完成，Tab 顺序与视觉顺序一致。
- 列表、菜单和下拉选择支持方向键及 Enter。
- 危险操作不能由一次误按 Enter 直接执行。
- 控件具有屏幕阅读器可识别名称，图标按钮同时提供可访问文本。
- 颜色对比度至少满足 WCAG AA，状态不只依赖颜色。
- 键盘焦点环始终清晰。
- 支持 Windows/macOS 系统缩放，200% 缩放下仍可完成核心操作。
- 遵循系统减少动态效果设置。
- 错误出现后提供错误摘要和合理焦点引导，不无条件抢走正在输入位置。

## Recommended Provider

- DayWay 与其他供应商使用相同尺寸的紧凑卡片。
- 通过“内置推荐”标签、柔和靛蓝边框或浅色背景体现推荐。
- 未配置时显示一行推荐说明和“开始配置”主按钮。
- 不使用大幅广告横幅、价格广告、倒计时、弹窗或持续动画。
- 不隐藏新增其他供应商入口。
- 配置完成后仅保留推荐标签，不持续高亮。
- 验证失败时正常展示错误，不用推荐样式掩盖失败状态。

## Empty States

- 没有供应商时显示欢迎说明、DayWay“开始配置”和“新增其他供应商”。
- 没有原生 Codex 环境时显示检测说明、重新检测和安装建议。
- macOS 不显示 WSL2 导航项。
- Windows 没有 WSL2 发行版时显示说明和官方帮助入口，不显示空表格。
- 没有可导出的已验证供应商时说明先完成供应商验证，并禁用导出。
- 只有外部配置时显示地址和模型摘要，提供重新验证并纳入 GPTEasy 的入口。
- 所有空状态都提供明确的下一步操作，不使用无内容的空白页面。

## WSL2 Page

- 使用紧凑列表，不使用数据表格或每发行版独立详情页。
- 每行展示发行版名称、默认用户、运行状态、当前供应商状态和待重启状态。
- 每行提供只包含已验证供应商的行内选择器，DayWay 验证后排在第一。
- 选择供应商后立即执行该发行版的切换。
- 已停止发行版在操作前提示将临时启动并在完成后恢复停止。
- 行内可展开查看实际配置路径、最近操作结果和技术错误。
- 页面顶部提供“应用到全部 WSL2”。
- 批量操作先选择供应商并确认受影响发行版，结果按发行版逐项展示成功、失败或待重启。

## Linux Script Export

- 始终导出当前全部已验证供应商，不提供逐个供应商选择。
- 未配置或未验证供应商不导出，DayWay 验证后在脚本菜单中排第一。
- 页面明确显示将导出的供应商数量，以及脚本包含明文 API Key。
- 没有已验证供应商时禁用导出，并引导用户先配置供应商。
- 外部 Linux 的当前供应商由脚本读取目标系统配置，不继承导出机器的当前状态。
- “复制脚本”为主操作，“保存为文件”为次操作。
- 复制或保存前固定提示脚本包含明文 API Key，不能公开、上传或提交到 Git。
- 默认不展开完整脚本，通过“显示脚本内容”主动查看。
- 切换 Shell 或语言后重新生成脚本。
- 保存文件使用 `gpteasy-providers.bash` 或 `gpteasy-providers.zsh`。
- 不直接修改本机或远程 Linux 的启动脚本，同时提供简短的手工安装说明。
