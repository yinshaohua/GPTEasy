# GPTEasy v0.1 UI Contract

<!-- release-contract: desktop-consumer-control=prohibited -->

> 本文是已经交付的 v0.1 历史基线。v0.1 之后的当前目标见 [`PROVIDER-MANAGEMENT-SPEC.md`](./PROVIDER-MANAGEMENT-SPEC.md)。

本合同只覆盖 Windows x64 首个可验收版本。界面只提供简体中文并始终跟随 Windows 主题，不包含搜索、分页、WSL2、Linux 脚本、DayWay、自动更新、诊断导出或登录启动设置。

## Experience

- GPTEasy 是安静、紧凑、工作导向的 Windows 工具，不使用营销首页、装饰性大卡片或说明功能的欢迎页。
- 设置窗口采用单实例；默认尺寸约 `960 x 680`，支持缩小、系统缩放和必要的纵向滚动。
- 左侧导航只包含供应商管理和未来页面项；首次打开进入供应商管理。
- 界面只显示用户完成当前任务所需的状态和操作，不暴露配置路径、SQL、进程参数或恢复状态机。
- 所有文案来自集中式简体中文消息资源，错误使用稳定消息 ID。

## Suppliers

- 页面使用紧凑列表加详情编辑区；列表不套卡片、不搜索、不分页，也不设置人为数量上限。
- 列表行显示名称、默认模型、验证时间和当前供应商标记；未验证输入不进入列表。
- 新建和编辑字段只有名称、服务地址、API Key 与默认模型。
- API Key 默认隐藏；完整显示和复制都需要用户明确操作，离开编辑区后重新隐藏。
- 服务地址和 API Key 完整后才能获取模型；默认模型只能从本次返回的模型列表选择。
- 验证依次展示模型确认、Responses 流式响应和工具调用闭环；失败立即停止，页面显示简短原因和可展开的脱敏技术详情。
- 新供应商验证成功后由用户执行“保存”；非当前供应商编辑后执行“保存”；当前供应商关键字段编辑后只能执行“保存并应用”。
- 验证成功本身不保存、不切换；取消、关闭窗口或离开未保存编辑时直接丢弃页面状态，不提示保存草稿。
- 名称修改不影响验证；服务地址、API Key 或默认模型变化后必须重新验证。
- 删除只对非当前供应商开放，并使用一次确认对话框。

## Codex Environment

- 页面顶部显示环境实际状态：当前供应商、OpenAI 登录模式、外部配置、管理冲突或待重启。
- 环境实际状态可以包含桌面 Codex、Codex CLI 的检测结果和被动待重启状态；检测不完整时明确显示无法确认。
- 切换到 OpenAI 登录模式只在本页提供；检测不到 Codex 已有登录凭据时禁用写入并提示先在 Codex 登录。
- OpenAI 登录模式生效后若凭据消失，保留模式并显示页面内警告，不自动改写配置。
- 外部配置只允许在选择已验证供应商、查看替换范围并确认后接管。
- 管理冲突只允许在重新选择已验证供应商、查看替换范围并确认后重新接管；无法安全解析时不提供强制覆盖。
- 供应商管理主界面不提供“恢复上次配置”入口。

## Confirmation

- 可靠确认没有运行中的 Codex 消费者时，从一个受管供应商切换到另一个供应商不二次确认。
- 消费者正在运行、检测不可信或未检测到消费者时，写入前显示一次确认，提供“继续切换”和“取消”。
- 从 OpenAI 登录模式选择供应商时必须确认；若同时存在进程风险，合并为同一个确认框。
- 外部配置接管、管理冲突重新接管和切换到 OpenAI 登录模式分别使用一次明确确认。
- 不提供自动重启、立即重启、倒计时或默认自动选择。
- 不提供启动、关闭、强制终止、激活或重启 ChatGPT/Codex 桌面版的入口；Codex CLI 也不由 GPTEasy 控制。

## Tray

- 顶部只读显示当前供应商、OpenAI 登录模式、外部配置、管理冲突或待重启。
- 中间只列出已验证供应商；当前供应商使用勾选标记，点击当前项不执行操作。
- 正常受管状态下点击其他供应商立即切换；风险场景复用设置窗口的确认规则。
- OpenAI 登录模式不作为托盘项；当前处于该模式时可以选择供应商并确认返回供应商模式。
- 外部配置和管理冲突不允许从托盘直接切换，相关供应商项不可用，用户通过“设置...”处理。
- 底部只有“设置...”和“退出 GPTEasy”。
- 关闭设置窗口后继续托盘驻留；第一次关闭仅显示一次非阻塞系统通知。

## Feedback

- 网络验证进度和字段错误保留在当前页面，不使用系统通知。
- 窗口可见时，成功或失败结果使用页面内状态；窗口隐藏时，托盘切换结果可以使用一次系统通知。
- 同一结果不重复展示页面消息和系统通知。
- 错误、通知、复制技术详情和可访问名称都不得包含 API Key、完整请求或响应正文。
- 待重启使用文字和状态圆点共同表达，不能只依赖颜色。
- SQLite 无法安全打开时显示阻塞恢复页，只提供恢复最新有效数据库备份和退出，不进入普通设置页。

## Accessibility

- 所有操作可通过键盘完成，并有稳定、可见的焦点顺序。
- 控件提供可读名称、状态和错误关联，满足屏幕阅读器操作。
- 在 Windows 200% 缩放下不遮挡、不重叠，长名称和长模型 ID 可以换行或省略并提供完整可访问文本。
- 高对比度模式下使用系统色和边框表达状态；成功、警告和错误同时使用图标或文字。
- 跟随 Windows 减少动态效果设置；除验证中的必要进度反馈外不使用循环动画。
