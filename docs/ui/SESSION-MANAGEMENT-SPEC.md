# 会话管理界面合同

> 本文描述当前会话管理界面合同，并覆盖 `PROVIDER-MANAGEMENT-SPEC.md` 早期版本中的阶段性导航约束。

## 产品边界

- 会话管理是当前 Windows 用户 Codex 环境的历史管理器，不恢复或继续会话，不发送消息，不审批工具调用。
- 只展示用户直接参与的桌面版、CLI、IDE 等用户交互会话；exec、子代理、自动化和其他内部来源不显示。
- Codex App Server 是唯一会话接口。不可用或版本过低时显示不可用状态和安装/升级指引，不读取私有 SQLite 或 rollout 文件。
- 页面不自动安装、升级、启动或控制用户的 Codex 消费者。

## 信息架构

- 左侧“会话管理”导航项已启用；页面直接进入历史列表，不显示欢迎页或功能介绍。
- 页面使用“会话”和“已归档”两个页签，共用搜索、项目筛选和会话供应商筛选。
- 默认跨全部项目查询，按最近更新时间倒序；搜索只匹配 App Server 稳定接口支持的标题或预览文本，不暗示正文全文搜索。
- 列表与详情采用前后两级页面，延续供应商管理的导航方式；返回列表时保留页签、筛选、搜索、已加载 cursor 和滚动位置。

## 会话列表

- 使用紧凑表格式列表，不使用装饰性卡片。行内显示标题或预览、项目路径、会话供应商、来源和最近更新时间。
- 缺失或无法识别的供应商按上游实际状态显示，不自动匹配当前供应商，也不重写历史 provider metadata。
- 使用 App Server cursor 和明确的“加载更多”；筛选、搜索或页签变化时取消旧查询并从首个 cursor 重新加载。
- 空结果、首次加载、加载更多、搜索无结果和 App Server 不可用是不同状态，不用空白列表替代错误。
- 会话页支持单项归档和多选归档；已归档页支持单项取消归档和多选取消归档。
- 批量归档逐项执行并逐项显示结果。部分失败保留成功项的实际状态，失败项可单独重试，不显示虚假的整体成功。
- 永久删除只作为单项危险操作出现，不进入多选工具栏。

## 会话详情

- 打开详情时通过 App Server 按需读取完整会话，不在列表加载期间预取所有正文。
- 详情顶部显示标题、项目路径、会话供应商、来源、创建时间和最近更新时间。
- 用户和助手内容按会话顺序展示；命令、工具调用及结果默认折叠，并可逐项展开。
- 详情提供 Markdown 导出、归档或取消归档以及永久删除，不提供恢复会话、发送消息或审批入口。
- Markdown 导出使用本次结构化读取结果，不解析 rollout。取消保存或写入失败不改变会话状态。

## 归档与删除

- 归档与取消归档是可恢复整理操作；永久删除是视觉和文案均独立的不可恢复操作。
- 外部 ChatGPT/Codex 桌面版、Codex CLI 或 IDE Codex 正在运行，或者消费者状态无法确认时，列表和详情保持可读，但所有归档、取消归档和永久删除入口禁用并显示简短原因。
- GPTEasy 自有的会话服务进程不计入上述外部消费者。
- 永久删除确认展示标题、项目、不可撤销说明和派生会话风险，并提供“先导出 Markdown”和明确的危险确认按钮。
- 导出不是删除前置条件，不要求输入标题或会话 ID。无法完整预览派生会话时明确说明范围无法完全列出，不显示未经证明的确定数量。
- 删除请求失去响应时不自动重试；刷新实际状态后显示会话仍存在、已归档或已删除的真实结果。

## App Server 状态

- 进入页面时按需无窗口启动 GPTEasy 自有 App Server；应用启动和仅托盘驻留时不预先启动。
- 离开页面后等待在途请求结束或取消，再经过短暂空闲宽限关闭；宽限内重新进入复用原进程。
- App Server 意外退出时至多自动重启一次。列表、搜索和详情读取可以自动重试一次，归档、取消归档和永久删除不得自动重试。
- App Server 不可用、版本不兼容、初始化失败、意外退出和自动恢复失败使用不同的稳定错误状态，并提供可执行的重试或升级入口。

## 可访问性与布局

- 搜索、页签、筛选、列表、批量归档、详情折叠、导出和确认流程均支持键盘与屏幕阅读器。
- 归档、下载、展开和删除使用一致图标、可读名称与必要 tooltip；危险操作不能只靠颜色区分。
- 默认窗口和最小 `680 × 520` 窗口下，表头、行操作、筛选器和详情内容不重叠；长标题、路径和供应商名可截断并提供完整可访问文本。
- 跟随 Windows 主题、高对比度和减少动态效果设置；加载状态不使用无法证明的百分比。
