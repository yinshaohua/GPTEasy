# DayWay README 宣传语核验

## 调查范围

- 访问日期：2026-08-17。
- 资料范围：仅使用 `dayway.site` 同域的官网、官方文档和公开 API；没有使用第三方测评。
- 待核验表述：价格很便宜、稳定又可靠、绘图方便、可开发票。
- 判断原则：官网自述可证明 DayWay 如何定价、提供了哪些能力以及如何描述自身，但不能充当独立的价格横评、可用性测量或用户体验测评。

## 结论

| 表述 | 第一方证据结论 | README 使用边界 |
| --- | --- | --- |
| 价格很便宜 | **部分支持。** 官网确实主打低价，并公开代表性价格和实时价格接口；“很便宜”仍是需要比较口径的评价。 | 可写“价格实惠”或“主打低价”，并注明实际价格以实时模型广场为准；不要写成独立测评结论。 |
| 稳定又可靠 | **仅支持站方自述。** 官网说明采用多渠道调度、自动切换和负载均衡，但没有公开 SLA 或足以验证长期可靠性的历史可用率。 | 可明确归属于官网自述，或作为 GPTEasy 项目方的推荐评价；不宜宣称已经客观验证。 |
| 绘图方便 | **功能事实充分，体验评价未独立验证。** 官方绘图台支持文本生成、参考图编辑、参数选择、预览和下载等完整流程。 | 宜改写为具体能力，例如“提供便捷的绘图台，支持文本生图和参考图编辑”。 |
| 可开发票 | **支持，但有条件。** 官方文档明确提供申请、进度查询和电子发票下载。 | 应写“符合条件的充值可申请电子发票”，并链接开票条件。 |

## 逐项证据

### 价格很便宜

1. [`https://dayway.site/api/home_page_content`](https://dayway.site/api/home_page_content)，官网“DayWay 服务首页内容”API 的“代表性价格 / 低价说明”栏目，2026-08-17 访问成功（HTTP 200）。页面给出的 2026-08-06 快照为：`gpt-5.6-sol` 输入 `¥1.15 / 1M`、输出 `¥6.90 / 1M`，并称通过“多渠道资源整合、分层定价与智能调度，降低综合使用成本”。同一栏目明确提示这只是代表性快照，实际价格以模型广场为准。
2. [`https://dayway.site/api/pricing`](https://dayway.site/api/pricing)，官方实时价格 API，2026-08-17 访问成功（HTTP 200）。访问时返回 13 个模型及其公开倍率、可用分组等字段，可证明 DayWay 提供公开的实时定价数据，但不能单独证明其相对于整个市场“很便宜”。
3. [`https://dayway.site/pages/docs/`](https://dayway.site/pages/docs/)，页面标题“DayWay 平台介绍 | DayWay 使用文档”，“基本信息”栏目，2026-08-17 访问成功（HTTP 200）。文档说明模型、分组和价格会随平台状态变化，实际选择以模型广场当前显示为准。

因此，“价格很便宜”应视为站方定位或推荐评价。最稳妥的事实性表达是“DayWay 主打低价，具体价格以实时模型广场为准”。

### 稳定又可靠

1. [`https://dayway.site/api/home_page_content`](https://dayway.site/api/home_page_content)，官网“DayWay 服务首页内容”API 的“稳定可靠”栏目，2026-08-17 访问成功（HTTP 200）。站方称其“智能调度多个上游资源，通过自动切换与负载均衡，减少单一渠道波动带来的报错”，并列出“多渠道调度、自动切换、负载均衡”。这是架构与营销自述，不是独立可用性测量。
2. [`https://dayway.site/api/status`](https://dayway.site/api/status)，官方状态 API，2026-08-17 访问成功（HTTP 200），返回 `uptime_kuma_enabled: true`。这只能证明访问时服务在线且监控功能已启用，不能证明长期稳定性。
3. [`https://dayway.site/pages/docs/`](https://dayway.site/pages/docs/)，页面标题“DayWay 平台介绍 | DayWay 使用文档”，“安全边界”栏目，2026-08-17 访问成功（HTTP 200）。官方文档明确提示，一次成功调用不代表其他模型、协议或后续请求始终可用。官网首页“使用须知”也写明上游状态会影响请求结果，任何分组都不承诺所有请求均成功。

未找到公开 SLA 或可复核的长期历史可用率，因此不能把“稳定又可靠”写成已经被本调查验证的客观结论。可以写：“据 DayWay 官网，其通过多渠道调度、自动切换和负载均衡降低单一渠道波动；实际可用性以服务状态为准。”

### 绘图方便

1. [`https://dayway.site/images/`](https://dayway.site/images/)，页面标题“DayWay 绘图台”，2026-08-17 访问成功（HTTP 200）。页面元描述说明可使用当前生效的本站 Token 完成文本生图与参考图编辑。
2. [`https://dayway.site/pages/docs/images/workbench.html`](https://dayway.site/pages/docs/images/workbench.html)，页面标题“使用 DayWay 绘图台 | DayWay 使用文档”，“开始生成 / 当前可用参数 / 工作台与画廊”栏目，2026-08-17 访问成功（HTTP 200）。文档明确支持文本生成、参考图编辑，允许选择尺寸、张数、质量、格式和背景，并支持搜索、筛选、预览、缩放、下载和会话管理。

这些资料足以证明绘图流程和功能存在；“方便”仍是体验评价。README 宜用“提供便捷的绘图台，支持文本生图和参考图编辑”，让“便捷”保持为推荐语，同时用具体能力承接。

官网首页内容 API 仍含“生图台即将开放”的旧文案，与已经上线且有完整文档的绘图台入口不一致。README 不应据此承诺成熟度，只陈述当前可访问能力。

### 可开发票

1. [`https://dayway.site/pages/docs/platform/invoices.html`](https://dayway.site/pages/docs/platform/invoices.html)，页面标题“DayWay 服务平台与发票 | DayWay 使用文档”，“哪些充值可以申请发票 / 提交申请 / 查看进度 / 下载电子发票”栏目，2026-08-17 访问成功（HTTP 200）。文档明确提供发票申请、进度查询和电子发票下载；当前文件类型为 PDF、PNG 或 JPEG。
2. [`https://dayway.site/api/notice`](https://dayway.site/api/notice)，官方公告 API，2026-08-17 访问成功（HTTP 200），公告为“电子发票服务已上线”，并链接发票服务。
3. [`https://dayway.site/account/invoices/`](https://dayway.site/account/invoices/)，页面标题“DayWay 平台”，2026-08-17 访问成功（HTTP 200）。发票记录属于账户私有信息，实际查看和申请需要登录。

开票不是无条件能力。官方文档要求充值已完成、完成时间在申请核验前 12 个月内、未被其他有效申请占用、没有需人工处理的退款或冲正信号，且所选充值实付合计至少为 `¥10.00`；最终资格以提交时重新核验为准。

## README 建议措辞

兼顾用户指定语气与证据边界，可写：

> GPTEasy 推荐 DayWay：价格实惠、使用稳定，提供便捷的绘图台，并支持为符合条件的充值申请电子发票。价格、模型可用性及开票条件以 DayWay 官网实时信息为准。DayWay 官网称其通过多渠道调度、自动切换和负载均衡降低单一渠道波动。

其中“价格实惠、使用稳定、便捷”属于 GPTEasy 项目方的推荐评价；绘图能力、调度机制和有条件的电子发票服务则有上述 DayWay 第一方资料支持。
