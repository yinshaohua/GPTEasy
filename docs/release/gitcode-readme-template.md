# GPTEasy 下载

本仓库只提供 GPTEasy 的国内更新清单和不可变 Release 下载，不是源码镜像，也不在这里构建程序。

正式稳定版本请从 Releases 下载 Windows x64 当前用户 NSIS 安装包，并使用同一 Release 中的 SHA-256 信息核对完整性。Tauri updater `.sig` 供 GPTEasy 内置公钥自动验证，不能替代 Windows Authenticode；当前安装包可能触发 SmartScreen 提示。

源码、Issue、Tag 和权威发布说明位于 GitHub `yinshaohua/GPTEasy`。`smoke-*` Release 与 `smoke/` 清单只用于 API 冒烟，不是正式版本。
