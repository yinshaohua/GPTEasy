# 独立 Linux 离线模型目录与能力门禁

#69 为独立 Linux 接受 schema v2 的离线目录协议：Rust 共享生成器从有效验证快照生成完整载荷，将供应商关键组合、默认模型、载荷字节摘要、导出来源和生成协议/策略固化为绑定。只维护显示名称不会改变模型集合；关键组合或模型集合变化须重新验证并导出。摘要表达载荷完整性，不是供应商验证或跨操作已应用证据。

明确切换时，脚本用 PATH 中的原生 Linux 外部入口在隔离 home 运行有限时的 App Server 探针，以 model/list 返回的固定模型和四档元数据确认目录/schema 能力。版本号不足以证明兼容性；没有 CLI 或不支持目录时停止，不允许只写默认模型。探针只拥有自己的临时进程，不使用用户共享后台服务的管理接口。此项取代 ADR-0028 对独立脚本“无 CLI 可预配置、仅检查最低版本”的门禁；桌面 WSL 版本门禁暂不改变。

在既有共享锁内先保存完整恢复点，再提交目标 home 的私有不可变目录，随后复核配置身份与并发内容并原子替换完整最小配置。首版保留完整孤立目录，不自动清理；配置提交后失败保留现场及恢复点，避免盲目覆盖新配置。恢复按原存在性、完整内容及旧目录引用进行，目录验证不依赖当前导出是否仍包含旧供应商。恢复点顺序使用锁内递增序号，以免系统时钟回拨选错目标。

这延续 ADR-0029/0048 的操作内核验与整体替换授权，不持久化 shell Saga。管理区块中的组合指纹、目录摘要及策略是工件绑定元数据；它们修订 ADR-0029 的“不保存组合指纹”表述，但不表示消费者已读取配置。切换和恢复统一提示“配置已保存，但 CLI/共享后台服务可能仍使用旧配置”，并说明目标用户/home。脚本不控制用户服务，不提供未经核验的重启命令。

本决策只接受 ADR-0054 中独立 Linux 的目录交付部分。WSL 桌面双向 schema v2 共同管理、共享后台服务发现/用户确认重启和真实交互菜单验收仍由后续工作完成；ADR-0054 保持 proposed。ADR-0053 的通用四档兼容策略在本范围复用，不表示上游模型已验证支持四档请求。
