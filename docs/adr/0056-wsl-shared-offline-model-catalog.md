# WSL2 桌面与脚本共同管理完整离线目录

2026-10-03，#70 将 ADR-0055 的 schema v2 接入 WSL2 桌面共同管理，扩展 ADR-0030 的工件协议及 ADR-0053 的四档平台范围。桌面从绑定已验证供应商组合的完整快照复用共享目录生成器，为全部发现模型提供 low、medium、high、xhigh 及默认 high；根级实际 effort 继续沿用既有映射。选择器元数据不代表供应商真实支持已验证。

桌面和 Bash/Zsh 识别同一受管区块、目录协议/策略、组合指纹、摘要和唯一根级绝对引用。目录保持私有不可变，先安装目录再原子替换配置；bundle/helper 升至 V3，拒绝旧 writer 接收新载荷。双方只恢复自己创建的备份，保留旧目录及中断遗留的孤立目录；目录缺失、损坏或绑定冲突时停止，避免写入悬空引用。schema v1 只读识别为缺少完整目录的旧格式，下一次明确应用才在备份和共享锁保护下迁移。

桌面只管理发行版注册身份、默认 Linux 用户及其默认 `$HOME/.codex`。脚本自定义 home 保持独立。只读协调比较供应商地址、凭据、默认模型和目录模型集合/策略；名称、来源 ID 和物理路径变化不构成关键组合变化。脚本使用旧快照时显示差异，保留实际工件；不会自动用桌面快照覆盖它或恢复已删除供应商。

显式应用在提交前用原生 Linux CLI 的隔离 App Server `model/list` 探针核验完整目录与四档元数据，拒绝 Windows 互操作入口、缺失 CLI 及 schema 不兼容；版本号仅为历史前置条件。探针只拥有临时 home 和自己的进程，不管理用户 daemon，不自动升级。

共享锁从实际工件读取前持续到 guest 写后复读及 Windows SQLite 提交完成。schema v12 在 WSL Saga 保存 config、credentials、catalog 的旧/新摘要，包含状态提交后中断的恢复窗口；仅旧状态或经过校验的新状态可收敛，第三种状态保留现场、锁及冲突证据。旧迁移记录中的未知目录摘要只用于无目录引用的历史操作。此决定保留桌面持久化 Saga 和 shell 操作内核验各自的边界。

磁盘提交与运行实例刷新分别表达。Running 环境保守显示 CLI/共享后台服务可能待刷新，不声称检测到服务，也不以重新打开终端证明刷新完成。只读列表对 Stopped 发行版零 guest 调用；可靠观察到停止时只清该环境旧实例待处理项。显式操作先释放锁和自有 guest 进程，最多观察自然停止十秒，仍运行时保留提示，不强制 terminate。

本决策接受 ADR-0054 中 WSL 目录交付及共同管理部分。主动 daemon 控制与跨平台真实交互菜单验收仍属后续工作，ADR-0054 保持 proposed；自动化及未执行项见 [#70 验收证据](../evidence/issue-70-wsl-shared-model-catalog.md)。
