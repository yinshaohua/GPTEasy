# 采用直接配置模式，不运行本地 API 代理网关

GPTEasy 直接修改当前 Windows 用户默认的 Codex 配置环境来切换供应商，不运行本地 API 网关，也不创建或修改系统、用户或终端环境变量。供应商地址、模型和 API Key 写入目标 Codex 版本支持的用户级配置及凭据载体，使桌面 Codex 与 Codex CLI 读取同一状态；具体文件和字段在实现开始时重新验证，旧 Spike 的实验字段不是永久合同。若目标 Codex 版本不再提供两类消费者共同读取的用户级凭据载体，该兼容性问题阻止发布，而不是退回环境变量拼接。

首个可验收版本不管理机器级配置、其他操作系统用户或自定义配置路径。若 `~/.codex/config.toml` 不存在，应用启动、供应商验证和供应商保存都不得创建它；只有用户明确切换供应商或切换到 OpenAI 登录模式时才允许创建。每次修改前完整备份将被改写的 `config.toml` 和供应商凭据载体，记录文件存在性并通过同目录临时文件、写后校验和平台安全替换避免部分写入；代价是已经运行的 Codex 消费者必须退出后才能读取新配置。
