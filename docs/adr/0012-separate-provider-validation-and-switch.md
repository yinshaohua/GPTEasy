# 供应商验证与环境切换严格分离

供应商验证成功只允许保存已验证供应商，不自动修改当前用户 Codex 环境。用户必须另行明确执行供应商切换，GPTEasy 才能创建备份并写入 `~/.codex`。这比首次验证后自动切换多一步操作，但避免网络验证产生隐藏文件副作用或意外覆盖外部配置，并使用户对环境修改给予清晰授权。

当供应商目录从空变为保存了第一个供应商时，保存成功后立即询问用户是否将该供应商应用到当前 Codex。确认仍属于独立、明确的环境修改授权，并复用完整的供应商应用流程；取消只保留已保存供应商，不修改当前用户 Codex 环境。后续新增供应商不显示此提示，用户通过目录中的“应用”按钮明确发起。
