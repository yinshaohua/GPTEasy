# 可信桌面启动与用户确认后的进程树重启

<!-- release-contract: desktop-consumer-control=trusted-start-confirmed-tree-restart -->

## 状态

本决定取代 ADR-0026 对 ChatGPT/Codex 桌面版的一律禁止控制；配置切换与桌面生命周期仍保持独立。ADR-0033 所定义的 GPTEasy 自有会话服务进程不受本决定影响。

## 决定

GPTEasy 在供应商管理页顶部被动展示 ChatGPT/Codex 桌面版运行状态。停止时可以启动，运行时可以在用户二次确认后重启。启动目标只能来自当前用户可发现的 OpenAI AppX 包，包名限于 `OpenAI.Codex` 或 `OpenAI.ChatGPT`，发布者 ID 必须为 `2p2nqsd0c76g0`；应用通过包 AUMID 激活，不接收或执行前端传入的路径。

消费者扫描必须按本次发现的安装目录复核桌面根进程。重启确认携带用户看到的 PID 与进程创建时间，并明确说明正常退出失败时将结束桌面进程及其中任务。后端在请求正常关闭前再次复核身份；每个桌面根进程只选择一个可信 Electron 主窗口发送 `WM_CLOSE`，不得向同进程的托盘消息窗口、输入法窗口或其它辅助窗口广播。若短暂观察后同一根进程仍驻留，后端必须再次复核 PID 与创建时间，只结束这些可信根及其在本次快照中的后代，并等待旧根消失。若复核时桌面版已经停止，则跳过结束请求并按可信启动流程重新激活；状态无法确认、出现不同根身份、旧根未消失、激活失败或未观察到新的可信根进程都返回失败，不能把结束请求或激活请求成功当成重启成功。

Codex CLI 的进程身份永远不进入桌面关闭集合，GPTEasy 不启动、关闭、终止或重启 CLI。供应商切换、OpenAI 登录模式切换和保存并应用继续只完成安全配置写入；用户可以另行选择桌面重启，但配置操作不会自动调用桌面控制命令。
