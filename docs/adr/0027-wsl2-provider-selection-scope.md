# 将 WSL2 单发行版供应商选择纳入当前路线

> ADR-0030 已取代本文的 Linux 导出延期、双工件凭据写入和只由桌面 SQLite 表达当前供应商的部分；ADR-0031 又将“强制恢复原停止状态”修正为安全优先的尽力恢复。发行版身份、默认用户范围和无副作用普通探测继续有效。

## 背景

ADR-0010 将 WSL2 和 Linux 切换脚本延后，当前代码也只保留了占位按钮。新的产品决定要求先交付 WSL2 供应商选择，但不把 Linux 脚本导出一并纳入本轮实现。WSL2 的发行版具有独立生命周期，临时启动、写入失败和运行中 Codex 的待重启状态都不能安全地作为一个全局环境处理。

## 决策

- 将 WSL2 供应商选择作为当前路线的独立能力；一次操作只处理一个可管理的 WSL2 发行版。
- 发行版是独立的受管环境，用户在明确确认后，从已验证供应商中选择目标并应用到该发行版默认用户的 Codex 配置。
- WSL2 探测保持无副作用；已停止发行版只有在用户明确应用后才可临时启动，操作结束时恢复原停止状态。运行中的发行版不因切换而终止，其中运行的 Codex 由用户自行重启。
- Linux 脚本导出继续延期，本轮只保留与 WSL2 并列的入口，不产生写入或成功反馈。
- 页面底部不再显示环境操作分组标题；“选择 WSL2 供应商”、“导出 Linux 脚本”和“切换到 OpenAI 登录模式”各占一行，主界面不提供恢复入口。WSL2 行展示首个可管理发行版的实际当前供应商名称、服务地址和已验证默认模型；弹窗选择只表示待应用目标。

## 取舍

按发行版逐个处理比批量切换增加了操作次数，但可以隔离不同发行版的生命周期、备份、并发冲突和失败恢复。把 Linux 脚本与 WSL2 同时实现会扩大凭据导出和 Bash/Zsh 兼容性风险，因此只统一信息架构，不提前承诺交付。

## 后果

WSL2 需要独立的环境身份、应用状态和可恢复切换操作；不能复用 Windows 当前环境的单一当前供应商字段。每个发行版的身份、当前供应商、配置/备份指纹和未完成操作必须可以独立恢复；目录竞态按不可变供应商 ID 重新校验，不能自动替换目标或重试。

WSL2 写入由 Windows Rust 在内存中渲染并重新解析候选 TOML，再通过 stdin 交给固定的 Linux guest writer。命令参数不得包含 API Key、服务地址、模型或配置正文；guest writer 负责 Linux 文件系统内的权限、备份、同步、替换、并发哈希检查和最近五份备份裁剪。

WSL2 供应商模式同时管理默认用户的 `config.toml` 和 `auth.json`。宿主把两个 UTF-8 工件组成带版本和长度的 stdin bundle；guest writer 不解析 TOML/JSON，只按长度写入临时文件，并在客体内以双工件 Saga 完成备份、并发检查、替换和失败回滚。只有两个新哈希都确认后才提交 WSL2 状态。

WSL2 专用 Saga 持久化 `prepared → artifacts_replaced → state_committed` 三个跨资源阶段；临时启动事实由 `originally_running` 与未完成操作共同表达，终态由未完成操作消失及发行版上的 `pending_restart` 表达。所有已启动分支都以 finally 语义恢复原停止状态，恢复失败时保留注意状态供刷新和人工处理。helper 安装在默认用户目录的版本化固定路径，不要求 root；安装/更新不携带供应商秘密。

探测阶段只做无副作用的 WSL2 探针和注册信息读取。不可确认使用 WSL2、不可唯一解歧或被识别为基础设施的发行版显示为不可选择；只有用户明确应用时才允许启动已停止发行版，并在所有结果路径恢复原停止状态。运行中发行版不因切换而终止，WSL 内 Codex 由用户自行重启。

## WSL2 环境变化协调

发行版注册身份是 WSL2 环境的稳定身份。相同注册身份改名时只更新显示元数据；注销后出现同名的新注册身份时不继承旧记录、供应商或备份。注册表默认 UID 变化时，旧记录进入需要重新确认状态，不向新用户复制配置；同一 UID 的主目录调整视为同一默认用户自己的配置位置变化。

WSL 暂时不可用、探测失败或应用前快照发生变化时，保留已有记录但禁止写入。应用在启动前、guest writer 前和生命周期恢复前重新确认注册身份、默认用户、可调用名称和原始运行状态；如果本次已经临时启动发行版，任何变化或失败路径都先恢复停止状态。

重启恢复发现发行版已注销、无法访问或身份不再匹配时，不根据数据库哈希猜测旧/新配置，也不尝试写入同名发行版；未完成 Saga 标记为需要人工处理，且不阻塞 Windows 当前用户 Codex 环境。发行版以相同注册身份恢复后，仍需用户显式刷新并重新应用。

## 实现边界

SQLite 追加迁移保存 WSL2 环境元数据、双工件最后应用哈希、当前供应商 ID 和单个未完成 Saga。Rust `wsl` 模块拥有探针、注册表解歧、guest bundle 和生命周期；Tauri 只暴露列举、刷新和应用命令。React 通过选择弹窗选择一个发行版和一个已验证供应商。
