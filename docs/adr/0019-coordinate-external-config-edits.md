# 区分可共存外部修改与管理冲突

GPTEasy 不持续监控或争夺 `config.toml`，只在启动、窗口刷新和执行操作前重新读取实际状态。管理区块之外的修改只要整份 TOML 有效就接受并保留；管理区块内容、边界或供应商 ID 被改动，以及区块重复、嵌套或残缺时进入管理冲突，停止切换和恢复。用户只能在设置中重新选择已验证供应商，查看影响和替换范围、重新备份并明确确认后重新接管；不按名称、地址、模型或被外部改动的 ID 自动匹配。预览或读取后任一受管工件指纹发生变化时，本次操作一律中止并要求从最新状态重试，不做隐式三方合并或无限自动重试。这样允许其他 Codex 设置正常共存，同时避免 GPTEasy 在无法证明所有权时覆盖配置。
