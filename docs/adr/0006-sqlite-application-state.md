# 使用 SQLite 保存应用内部状态

GPTEasy 使用由 Rust 后端独占访问的用户级 SQLite 数据库保存供应商、明文 API Key、验证状态、各受管环境的当前供应商和应用设置，并通过事务保持关联状态一致。React 前端只能通过受控的 Tauri command 访问这些数据；Codex 原生配置、配置备份和诊断日志继续使用普通文件。

数据库使用永久保留的顺序迁移，所有正式发布版本都必须能够跨多个版本直接升级到最新版。迁移前完整备份数据库并默认保留最近三份，迁移在事务中执行且失败时回滚，不能通过自动清空数据继续运行。旧版 GPTEasy 检测到更高版本数据库时拒绝写入；需要降级时必须恢复升级前备份。CI 保存历史数据库样本并验证各历史版本到当前版本的升级路径。
