# 首个版本不自动重启 Codex 消费者

首个可验收版本只检测桌面 Codex 和 Codex CLI，不关闭、终止、重启或恢复任何消费者进程。切换前若存在运行中的消费者，或者进程检测无法得出可信结果，用户只能选择继续或取消；检测不确定不阻止用户继续。继续后完成配置写入，并统一标记为待重启，不增加第三种持久状态；有待重启时托盘驻留低频重新枚举切换前的消费者，应用启动、设置页打开和用户刷新时也重新协调；只有可靠检测确认切换前的消费者已经全部退出，待重启才自动清除，新启动的消费者不阻塞清除。该选择牺牲自动立即生效的便利，避免中断任务、把检测失败误报为已经生效，以及尚未完整验证的进程身份和会话恢复风险。
