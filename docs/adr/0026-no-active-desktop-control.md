# 移除所有主动桌面控制入口（历史决定）

## 状态

已取代 ADR-0025，并恢复和收紧 ADR-0020 的被动消费者协调原则。

ADR-0033 后续补充了边界：本文继续禁止控制用户的 Codex 消费者，但允许 GPTEasy 为会话管理启动并独占一个不承载用户工作的 App Server 协议子进程。

## 决定

GPTEasy 不提供也不注册启动、正常关闭、强制终止、激活或重启 ChatGPT/Codex 桌面版的产品能力。用户从终端运行并承载工作的 Codex CLI 同样永远不由 GPTEasy 启动、关闭、终止或重启。ADR-0033 定义的会话服务进程是 GPTEasy 自有的协议端口，不属于这里的用户消费者控制能力。

消费者扫描、路径和父子关系身份分类继续保留，只用于展示环境实际状态、判断切换前的消费者是否仍然存在，以及协调被动的“待重启”状态。配置切换完成后，运行中的桌面版或 CLI 不被中断；用户需要在各自原入口自然退出并重新运行，GPTEasy 不提供立即重启、强制关闭确认、激活结果或重启成功条件。

这一决定删除前后端公开命令、控制器和界面入口，避免产品路径重新获得进程控制权限。环境写入的完成边界仍是安全配置写入和环境实际状态协调，而不是消费者生命周期变化。
