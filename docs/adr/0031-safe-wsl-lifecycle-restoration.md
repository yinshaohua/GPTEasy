# 临时启动 WSL2 后不强制终止发行版

桌面 GPTEasy 无法原子判断一个临时启动的 WSL2 发行版是否刚被用户打开了新会话；发行版内共享锁只能协调桌面和 Linux 导出脚本，不能阻止普通 WSL 会话启动。因此，对原本 Stopped 的发行版执行用户明确授权的刷新、核验或切换后，桌面退出自己的 guest 进程并在有限时间内等待发行版自然停止，但不得调用发行版级强制终止来保证恢复 Stopped。

配置读取或写入及桌面 SQLite 协调完成后先报告配置操作结果并释放共享配置锁，再以“等待自然停止”状态只读观察最多 10 秒。发行版自然停止时恢复原生命周期；等待后仍为 Running 时保留其实际运行状态，记录 WSL2 环境变化并向用户说明没有强制终止，后续操作按 Running 环境处理。这个取舍放弃了 ADR-0027 和旧 Spike 中“所有路径都必须恢复 Stopped”的绝对保证，以避免中断用户会话或其中的工作负载。
