# 通过 function 长期独立切换 Linux 供应商

Linux 导出物不是供应商列表或一次性初始化脚本，而是可长期使用的 shell function 集合。脚本被用户复制到其他 Linux 系统后，调用交互式 function 会列出当前供应商和脚本内可用供应商，用户确认选择后才修改当前 Linux 用户的 Codex 配置，也可以直接退出不做修改。切换只修改带有明确注释边界的 GPTEasy 管理区块，保留其他 Codex 配置；区块损坏、重复或存在歧义时停止修改。写入前创建带时间戳的备份，默认保留最近五份。脚本只依赖 Bash 4+ 或 Zsh 5+ 及常见基础命令，不依赖 Python、Node.js、第三方解析器、辅助二进制或 GPTEasy 可执行文件。此过程不依赖 GPTEasy 继续运行，也不自动与 Windows 宿主应用或 WSL2 状态同步。这样可以满足用户脱离桌面伴侣程序后仍能切换供应商的需求，但导出物必须自包含供应商配置和明文凭据。
