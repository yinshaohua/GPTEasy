# 只提供恢复上次修改前配置

每次实际修改当前用户 Codex 配置前，对将被改写的 `config.toml` 和供应商凭据载体分别创建带时间戳的完整备份，记录原文件是否存在，并默认保留最近五份；首个可验收版本不建设备份列表或通用恢复管理器，只在设置中提供“恢复上次修改前配置”。恢复前验证备份由 GPTEasy 创建、内容完整且 TOML 可解析，并先保全当前受管工件；若任一工件在上次操作后被外部修改则停止，不用旧备份覆盖新修改。恢复成功后重新读取受管工件并协调 SQLite 的最后应用证据和待重启状态，供应商目录记录不删除；自动故障对账仍独立存在，手动恢复只用于用户撤销一次已完成的切换或接管。
