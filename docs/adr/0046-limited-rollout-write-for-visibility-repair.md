# 会话可见性修复允许受限改写 rollout

常规会话读取和修改继续遵循 ADR-0034，只使用官方 App Server；但 App Server 当前无法修复模式切换后已索引会话的运行供应商，因此用户二次确认的会话可见性修复是受限例外。该流程仅处理身份明确的普通已索引会话，在模式、候选、消费者和存储能力复核通过后原子替换 `session_meta.payload.model_provider`，保留紧凑恢复清单，并由干净 App Server 验证全量及目标供应商视图不变量；缺失索引留给独立的索引协调流程。CLI、身份不明消费者或最终状态无法判定时流程必须失败关闭，且后者阻止 Codex 重启。

本决策只取代 ADR-0034 对上述可见性修复场景“不得解析或写入 rollout JSONL”的限制，也构成 ADR-0036 对外部消费者不阻断会话修改规则的特例；归档、取消归档、删除、读取和搜索仍不得直接操作 Codex 私有存储。
