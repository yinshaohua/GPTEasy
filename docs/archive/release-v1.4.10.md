# GPTEasy v1.4.10 变更归档

发布日期：2026-09-28

## 用户可见变更

- 修复外部桌面重写或未来版本扩展受管 Codex 配置后，GPTEasy 将仍可识别当前供应商并保留未知受管字段的问题。
- 启动检查改为校验受管供应商路由身份和已应用证据，避免仅因模型、格式或兼容字段变化而错误阻断应用。
- 启动冲突问题日志增加脱敏阶段标记，用于区分配置匹配、已应用证据和凭据匹配阶段，不记录服务地址、凭据或完整配置内容。

## 兼容与安全边界

- 受管区块仍必须具备有效的供应商 ID、Responses 路由和必需的服务配置；不完整、不可解析或路由身份不一致的配置继续进入冲突处理。
- 供应商路由身份仍绑定已应用的不可变供应商 ID、服务地址和 Responses 认证约束；未知模型或未来字段不会改变这一检查。
- 修复继续保留原有备份、原子写入、并发检查、失败恢复和敏感信息脱敏边界。

## 验证记录

- 维护者已完成与本次变更相称的人工测试并明确确认通过。
- 完整 Rust 回归覆盖受管配置兼容、历史供应商别名、桌面重写恢复、未来字段保留和启动路由身份检查。
- 正式候选还须通过前端检查与测试、双视口布局、Issue #28 综合 acceptance、发布树、发布合同、更新信任根、Windows x64 NSIS 构建和 updater 签名验证。
- 未执行的交互式 Windows UAT 不记录为本版本已通过的自动化结果。

## 发布范围

- 本次正式发布版本为 1.4.10；GitHub Release 是正式发布源。
- Gitee 标准 Windows x64 安装包继续由维护者从网页上传 GitHub Release 中的同一安装包，自动同步在匿名字节校验通过后推进正式更新清单。
- 本次发布范围仍为 Windows x64 当前用户 NSIS 安装；Windows ARM64、macOS Intel、Apple Silicon、签名、公证和严格 `~/Applications` 安装不在本次交付声明内。
