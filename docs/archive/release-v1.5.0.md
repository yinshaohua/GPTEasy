# GPTEasy v1.5.0 变更归档

发布日期：2026-10-08

## 用户可见变更

- 修复切换不同供应商时模型选择和思考深度选择不一致的问题；模型目录按当前供应商和环境重新获取。
- 增加模型推理能力发现和刷新反馈，桌面 Codex 重启后可补偿刷新模型目录，并提供手动刷新入口。
- 完善 WSL2 与 Linux 导出环境中供应商切换后的守护进程刷新与失败诊断。

## 验证与范围

- Windows x64 当前用户 NSIS 安装包作为本次正式发布产物；其它平台不在本次交付声明内。
- 正式候选需通过前端、Rust、布局、综合验收、发布合同和 updater 签名等自动门禁。人工测试结果由维护者另行确认；未执行的交互式 Windows UAT 不记录为通过。
- GitHub Release 是权威发布源。Gitee 的标准 `.exe` 由维护者从网页上传同一安装包，自动同步通过匿名校验后才推进更新清单。
- 安装包若未做 Authenticode 签名，Windows 可能显示 SmartScreen 警告；updater 签名仍须通过验证。
