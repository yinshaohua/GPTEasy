# GPTEasy v1.5.4 变更归档

## 用户可见变更

- 修复「刷新模型目录」在 Codex 后台服务仍在优雅退出时过早报错的问题。重启命令的等待上限由 10 秒调整为 90 秒，命令成功退出后仍会查询服务状态。
- 区分无法连接后台服务、状态查询失败和协议响应异常。重启前失败会明确提示未执行刷新；重启后无法确认服务状态时，不把刷新结果报成成功或催促立即重试。
- 供应商配置保存结果与后台刷新结果分别显示。后台刷新失败不回滚已保存的配置。
- 问题日志记录失败阶段、CLI 来源类别、重启命令状态及可取得的退出码。标准错误输出只做限长分类，不记录原文或本机路径。

## 交付范围

- 正式安装包面向 Windows x64 当前用户；安装包可能触发 Windows SmartScreen 提示。应用更新使用独立的 updater 签名。
- GitHub 为权威发布源。Gitee 分发同一个安装包，维护者在网页上传后，由同步工作流验证附件并推进更新清单。
- 回归用例覆盖残留控制入口与连接拒绝、响应格式异常、重启后查询失败和超过原 10 秒上限的命令。自动门禁和人工测试状态以正式候选的验收记录为准。
