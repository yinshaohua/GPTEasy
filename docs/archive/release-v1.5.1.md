# GPTEasy v1.5.1 变更归档

发布日期：2026-10-16

## 用户可见变更

- 修复 WSL2 发现过程把注册表辅助配置项当作发行版读取，导致整个发行版列表不可用的问题；补充注册表失败阶段与错误码的脱敏诊断。
- 原生、WSL2 和 Linux 导出环境统一写入 512000 token 上下文窗口和 400000 token 自动压缩阈值，并处理已有配置的迁移。
- 移除模型目录中固定的 128000 token 上下文声明，避免与环境配置冲突。

## 验证与范围

- Windows x64 当前用户 NSIS 安装包为本次发布目标。
- 正式候选须通过前端检查与测试、布局测试、完整 Rust 回归、综合验收、发布树、发布合同、更新信任根及 updater 签名验证。
- 人工测试结果须由维护者明确确认；未执行的交互式 Windows UAT 不记录为通过。
- GitHub Release 为权威来源；Gitee 安装包由维护者通过网页上传，自动同步核验后再推进国内更新清单。
