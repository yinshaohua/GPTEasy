# GPTEasy v1.4.1 变更归档

发布日期：2026-08-29

## 用户可见变更

- 新增会话可见性检查与修复，可在 OpenAI 登录和供应商模式之间协调未删除的用户交互会话，并保持原归档状态。
- 修复预览会明确区分可执行、Codex CLI 正在运行、消费者身份未知、桌面版正在运行、App Server 不可用、配置阻断和索引 schema 不受支持等状态。
- 修复结果不再统一显示通用失败，而是区分写入前拒绝、候选变化、部分成功、写入后验证失败和恢复状态无法判定，并保留可重试项。
- 兼容 Codex 0.150.1 的完整线程索引合同；未知、增加额外索引或触发器的 schema 仍然失败关闭。
- 统一应用级标题栏与页面工具栏；普通新增、刷新、修复、导出、查看和设置操作使用白底边框按钮与彩色 Lucide 图标。
- 恢复 GPTEasy 1.4.0 写入的 WSL2 历史 schema 1 配置识别，并为真正的管理冲突提供带备份和再次确认的受控重新接管流程。

## 会话修复安全边界

- 只处理身份明确的 Windows 当前用户 Codex 会话，排除 exec、自动化、子代理、远程 host、损坏及身份歧义记录。
- Codex CLI、身份未知消费者或桌面消费者存在时允许只读扫描，但拒绝会话写入；GPTEasy 不终止用户的 CLI。
- 执行前复查目标 revision、候选哈希和消费者状态，防止扫描与确认之间的状态变化造成误写。
- rollout 采用原子替换；索引优先由 App Server 协调，直接 SQLite 后备仅限精确支持的 schema，且不清理既有索引。
- 每次执行保留最小脱敏阶段、错误码、计数、schema、消费者、写入和恢复状态，不记录标题、正文、工作目录、完整 thread ID 或凭据。
- 含加密内容的候选只修复结构化可见性字段，并继续提示后续续聊或压缩兼容风险。

## 验证记录

- 完整 Rust 回归通过；会话可见性 fixture 覆盖 Codex 0.150.1 schema、消费者竞态、部分成功、验证失败、恢复判断和日志脱敏。
- React 页面与 Gitee 同步协议测试通过；会话页面覆盖 readiness、执行失败映射、写入后验证失败和按钮语义。
- Playwright 覆盖 `680 x 520` 与 `1120 x 800` 视口，工具栏、页签、提示和按钮无重叠或截断。
- Windows 当前用户只读诊断验证全供应商视图、当前供应商过滤视图和候选差值，不输出会话内容或身份；计数会随新会话变化，不作为固定合同。
- 维护者已确认与本次变更相称的人工测试通过，并明确授权发布 1.4.1；未执行的可选深度 UAT 不记录为通过。

## 发布与平台范围

- GitHub 继续作为源码、Tag、Windows x64 构建产物和中文发布说明的权威来源；正式 GitHub Release 发布后同步同一产物到 Gitee。
- Windows 安装包保持当前用户 NSIS 安装和用户确认更新，不执行静默安装。
- Windows ARM64、macOS Intel、Apple Silicon、签名、公证和严格 `~/Applications` 安装仍需对应原生环境验证；本次 Windows x64 发布不宣称这些平台已完成交付。
