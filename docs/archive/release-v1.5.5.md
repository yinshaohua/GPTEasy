# GPTEasy v1.5.5 变更归档

## 更新检查

- 启动或每日检查遇到临时网络故障、限流或部分服务端错误时，依次等待 30 秒、2 分钟、10 分钟，最多自动重试三次。服务端返回有效的 `Retry-After` 时可以延后检查。成功或用完重试次数后恢复每日检查。
- 更新窗口显示下次自动重试时间，并提供「立即重试」。手动检查成功会取消剩余重试。检查失败时，已通过签名验证的待安装更新仍可安装。
- 问题日志记录失败阶段、触发来源、尝试次数和可用的 HTTP 状态或系统错误码，便于排查间歇性连接中断。日志字段仅包含脱敏的结构化信息。

## 交付范围

- Windows x64 当前用户安装包使用独立的 updater 签名。Windows SmartScreen 可能显示提示。
- GitHub 提供正式安装包。Gitee 同步同一安装包，并在附件校验完成后推进应用更新清单。
